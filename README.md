# Soenneker.Playwrights.Tests.Unit

A hosted unit test for testing with Playwright.

## Install

```bash
dotnet add package Soenneker.Playwrights.Tests.Unit
```

## What you get

- `PlaywrightUnitTest` — A hosted unit test for testing with Playwright.

## API at a glance

| API | What it does | Result / important behavior |
| --- | --- | --- |
| `PlaywrightUnitTest.TestHost` | Gets test host. | Gets test host. |
| `PlaywrightUnitTest.BaseUrl` | Gets or sets base url. | Gets or sets base url. |
